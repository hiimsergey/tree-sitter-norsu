# tree-sitter-norsu
The official [Tree-Sitter](https://tree-sitter.github.io) grammar for the [Norsu](https://github.com/hiimsergey/norsu.nvim) markup language.

## Roadmap
v0.X.0:

1. [ ] paragraphs and H1 headings
2. [ ] H2-H6 headings
3. [ ] inline bold
4. [ ] non-nested bullet lists
5. [ ] nested bullet lists
6. [ ] code blocks

### NOTE
- tables requires at least two lines (header + content)
- who can connect with paragraph:
	- lists
	- quotes
	- code
	- not tables
