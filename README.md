# tree-sitter-norsu
Official [Tree-Sitter](https://tree-sitter.github.io) grammar for the [Norsu](https://github.com/hiimsergey/norsu.nvim) markup language.

## Roadmap
v0.0.X:

1. [X] paragraphs and H1 headings
2. [X] H2-H6 headings
4. [ ] line comments
5. [ ] block comments
6. [ ] block quotes
7. [ ] code blocks
8. [ ] inline bold
9. [ ] other inline markup
10. [ ] tags
11. [ ] basic links
12. [ ] links with aliases
13. [ ] non-nested bullet lists
14. [ ] nested bullet lists
15. [ ] alphabetic lists
16. [ ] frontmatter
17. [ ] tables

### NOTE
- tables requires at least two lines (header + content)
- who can connect with paragraph:
	- lists
	- quotes
	- code
	- not tables
