# tree-sitter-norsu
Official [Tree-Sitter](https://tree-sitter.github.io) grammar for the [Norsu](https://github.com/hiimsergey/norsu.nvim) markup language.

## Expected roadmap

### v.0.X.0
- [X] 1: paragraphs and H1 headings
- [X] 2: H2-H6 headings
- [X] 3: links
- [ ] 4: inline bold
- [ ] 5: other inline markup
- [ ] 6: separators
- [ ] 7: code blocks
- [ ] 8: tags
- [ ] 9: URL links
- [ ] 10: block quotes
- [ ] 11: callouts
- [ ] 12: escaping
- [ ] 13: non-nested bullet lists
- [ ] 14: nested bullet lists
- [ ] 15: alphabetic lists
- [ ] 16: checklists
- [ ] 17: frontmatter
- [ ] 18: tables

### v1.X.0
- [ ] 1: comments
- [ ] 2: footnotes
- [ ] 3: side margins

### NOTE
- tables requires at least two lines (header + content)
- who can connect with paragraph:
	- lists
	- quotes
	- code
	- not tables
