# tree-sitter-norsu
Official [Tree-Sitter](https://tree-sitter.github.io) grammar for the [Norsu](https://github.com/hiimsergey/norsu.nvim) markup language.

## Expected roadmap
v0.0.X:

- [X] 1: paragraphs and H1 headings
- [X] 2: H2-H6 headings
- [X] 3: links
- [ ] 4: inline bold
- [ ] 5: other inline markup
- [ ] 6: code blocks
- [ ] 7: tags
- [ ] 8: block quotes
- [ ] 9: callouts
- [ ] 10: escaping
- [ ] 11: comments
- [ ] 12: non-nested bullet lists
- [ ] 13: nested bullet lists
- [ ] 14: alphabetic lists
- [ ] 15: checklists
- [ ] 16: frontmatter
- [ ] 17: tables

### NOTE
- tables requires at least two lines (header + content)
- who can connect with paragraph:
	- lists
	- quotes
	- code
	- not tables
